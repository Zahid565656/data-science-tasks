# Data Science & Analytics Internship – Phase 1

This repository contains the solutions for Tasks 1, 4, and 5 completed as part of the Data Science & Analytics Internship Program at DevelopersHub Corporation.

## Tasks Completed

### Task 1: Exploring and Visualizing the Iris Dataset

**Objective:** Understand how to read, summarize, and visualize a dataset.

**Approach:**

* Loaded the Iris dataset using Pandas.
* Explored dataset structure, columns, and summary statistics.
* Created scatter plots, histograms, and box plots using Matplotlib and Seaborn.
* Analyzed relationships between flower features and species.

**Key Insights:**

* Petal length and petal width are strong indicators for distinguishing Iris species.
* The dataset contains no major outliers and is well-balanced.
* Visualizations clearly show differences among species.

---

### Task 4: Predicting Insurance Claim Amounts

**Objective:** Estimate medical insurance charges using personal information.

**Approach:**

* Performed data exploration and preprocessing.
* Visualized the impact of age, BMI, and smoking status on insurance charges.
* Trained a Linear Regression model to predict insurance costs.
* Evaluated model performance using MAE and RMSE.

**Key Insights:**

* Smoking status has the strongest impact on insurance charges.
* Higher BMI and age generally lead to increased medical expenses.
* The regression model successfully captured major cost patterns.

---

### Task 5: Personal Loan Acceptance Prediction

**Objective:** Predict which customers are likely to accept a personal loan offer.

**Approach:**

* Explored customer demographics and banking information.
* Performed data preprocessing and feature analysis.
* Trained a classification model using Logistic Regression/Decision Tree.
* Evaluated model performance and analyzed customer segments.

**Key Insights:**

* Customer income and financial profile significantly influence loan acceptance.
* Certain customer groups show a higher likelihood of accepting loan offers.
* Classification models can effectively support targeted marketing decisions.
